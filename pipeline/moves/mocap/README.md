# Motion capture the move library is built from (ADR-0030)

| File | What | Licence |
|---|---|---|
| `quaternius-ual1.glb` | Quaternius, *Universal Animation Library* (Standard, no root motion): 43 clips on the Unreal mannequin, incl. `Idle_Loop`, `Spell_Simple_*`, `Hit_Chest`, `Death01` | CC0 1.0 (public domain), https://quaternius.com/packs/universalanimationlibrary.html |

`../sources.json` names each source's file, frame rate, reference pose (a T-pose frame, matched to the skeleton's
T-pose rest) and bone map. Another source (a Mixamo download, another CC0 library) is added there with its own map;
check its licence first and note it here.
