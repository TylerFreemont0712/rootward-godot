# ADR-0010: a clear battle work surface

- Status: battle work surface retained; Verifier contract superseded by ADR-0011
- Date: 2026-09-25
- Related: ADR-0006, ADR-0009, ADR-0011

## Decision retained

The title groups journey selection and preparation. Artificer owns Python/JavaScript selection and the three battle looks. Cards commit a click on mouse release, so a drag can begin before a source card disappears. Cards lift, deal, and settle. During a cast, code occupies the work surface below the arena, then closes before stage effects begin. The work surface keeps a fixed measured height through this exchange to preserve the arena framing. The run header, map, and supporting panels use a consistent hierarchy.

## Superseded decision

The initial Verifier reused Shardrun cards and asked for a bolt count/role contract, granting mana or block. This added a small combat bonus but did not create a different programming practice loop. ADR-0011 replaces it with a standalone code-reading course.
