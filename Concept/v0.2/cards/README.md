# Card face concepts · v0.2

Four standalone card artworks explore different hand-card footprints. Open the SVGs directly to compare the layouts; the matching PNGs are high-resolution previews rendered at 3×.

| Design | Card size | Direction |
|---|---:|---|
| [Console](01-console.svg) · [PNG](01-console-preview.png) | 164 × 232 | Framed portrait; distinct role, hook, and complexity bands |
| [Big-O first](02-big-o.svg) · [PNG](02-big-o-preview.png) | 184 × 258 | Larger portrait; complexity leads the read |
| [Terminal tile](03-terminal.svg) · [PNG](03-terminal-preview.png) | 152 × 216 | Compact, terminal-inspired tile with strong code labels |
| [Wide cartridge](04-cartridge.svg) · [PNG](04-cartridge-preview.png) | 224 × 184 | Landscape cartridge with a dedicated art bay |

Each card shows the same example, `import copy`: cost 1, role IMPORT, O(1) CONSTANT complexity, and a BEFORE STRIKE hook. Art uses `game/assets/shardrun/card-import-copy.png` with aspect-preserving bounds so the complete illustration remains visible. Role and complexity use separate labels and colors; compact layouts keep their text brief instead of shrinking it.

These are concept assets only. No live card UI or production assets are changed.
