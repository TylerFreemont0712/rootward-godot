What these concepts protect

Image safe area
Keep the whole source illustration visible with contain-fit inside a fixed viewport. Clip only the viewport; never crop the asset to make it fit.

Different labels stay different
Role (IMPORT / STRIKE / WARD) gets one chip. Complexity (O(1) / O(n)) gets a separate high-contrast block.

Hold-card hierarchy
Name and cost first, then art, then role and work. Summary text can stay in hover details when a compact footprint needs the room.

Scale changes the layout
Compact hides supporting copy; larger cards can show one sentence. It never shrinks every label until it is unreadable.
