# Lanternroot update handoffs

This folder is the rolling handoff point for Lanternroot work. Keep dated progress and review notes here as the town,
art or workflow changes. Record new or replaced art in [artchecklist.md](artchecklist.md): name the output, who or
what created it, the source/reference, the processing steps, and whether it is a candidate or shipped game asset.

## Current notes

- [updateprogress.md](updateprogress.md) — 2026-10-09 town layout, pixel workflow and review status
- [overhaul-2026-10-10.md](overhaul-2026-10-10.md) — the town overhaul: what was built, how to see it, the checks and the open items
- [artchecklist.md](artchecklist.md) — art sources and processing for this update, including unaccepted candidates
- [art-source/](art-source/) — original ChatGPT Image Generation sources for the Root Gate candidates

When an art candidate is not selected, keep it marked as a candidate and out of the runtime asset path. Do not describe
an existing or inherited image as ChatGPT-created unless its source record says so. The pipeline manifest remains the
source of truth for ComfyUI seeds, picks and prompts; this folder records changes and provenance that the manifest
does not cover.
