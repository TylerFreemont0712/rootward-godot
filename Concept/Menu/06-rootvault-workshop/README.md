# 06 · Rootvault Workshop

A warmer, more fantastical underground workshop: brown stone, copper root lines, an old reading bench and terraced chambers descending toward the Kernel. A thin command strip sits at the top; selected sections unfold beneath it. Resume is a compact note at the right, leaving most of the world visible.

## Movement and art

The top command strip keeps the current destination visible. Play opens a small mode panel beneath its button; the selected mode proceeds to setup and the map. Back or Escape restores the previous screen. Character opens a narrow skin list beside the ordinary in-game actor, with a separate **Use this skin** confirmation. The preview saves the selected skin in browser storage and reuses it in menus and battles.

The descent map takes a diagonal route through connected lower terraces. Every connector goes to a deeper room. The encounter note occupies an open corner rather than replacing the map. Brown and gold dominate; purple stays in shards and code accents.

The battle uses the same hand, program slots, piles, hero/foe staging and code pane as Kernel Foundry, so choosing the world theme does not require relearning Shardrun. The simple cutout drawing is a layout study; richer stylized environment and character art would follow selection.
